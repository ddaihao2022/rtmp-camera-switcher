📹 RTMP Camera Switcher
专业多摄影设备管理系统
桌面级多路 RTMP 视频切换台 · 支持实时预览、HDMI 输出、音频混音、录制与水印
⚡ Electron 31 ⚛️ React 18 🎥 多机位切换 🔊 音频混音 📺 HDMI 输出 ⏺️ 实时录制
⭐ Star on GitHub

✨ 核心功能

📺
多路预览
单屏/网格视图，最多同时预览 4 路，实时监控所有机位画面质量
🖥️
HDMI 输出切换
任意流全屏输出到第二显示器，切换实时生效，支持数字快捷键
🎚️
音频混音台
独立窗口，VU 表 + 频谱 + 音量推子 + 静音，不额外拉流
📁
本地媒体导入
将本地视频/音频作为虚拟流，与直播流同等操作和管理
🖼️
水印叠加
文字或图片水印，低透明度叠在输出画面，支持位置自定义
⏺️
输出录制
录制当前输出画面，WebM/MP4 格式，系统对话框保存
⚡
低延迟播放
禁用 GOP 缓存 + 自动追播，延迟 < 1 秒
⌨️
数字快捷键
按 1-9 直接切换输出源，适合节奏较快的现场导播操作

🚀 快速开始

# 安装依赖
npm run install-all

# 开发模式
npm run dev

# 打包构建
npm run build

推流到 rtmp://<本机IP>:1935/live/camera1 即可使用
